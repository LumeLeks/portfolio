# portfolio

Сайт-портфолио [lumeleks.ru](https://lumeleks.ru). Чистый HTML, CSS и JavaScript, без фреймворков и сборщиков.

## Идея

Хотелось оживить картинку, но не превращать её в мультик, поэтому всё движение сделано текстом: по траве бегают ASCII-человечки, а в небе за цветами падают цифры.

## Как устроено

- **Слои.** Коллаж разрезан на небо (`sky.jpg`) и передний план с прозрачностью (`fg.webp`). Между ними лежит `<canvas>` с цифрами, поэтому цифры уходят за стебли.
- **Человечки.** Четыре кадра бега из символов, для бега влево кадры зеркалятся. Линию гребня холма я сняла с картинки по точкам: бегуны встают на неё и наклоняются по склону. Дорожек три, дальние бегуны меньше и медленнее.
- **Клик по траве** добавляет бегуна на ближайшую дорожку.
- **Любой экран.** Картинка масштабируется как `object-fit: cover`, и по тем же формулам пересчитываются координаты бегунов и цифр, поэтому они не съезжают.
- **Переход.** Главный экран липкий, а основная часть наезжает на него прозрачным градиентом цвета травы, и картинка плавно перетекает в фон.
- **Заставка** показывает настоящий процент загрузки картинок и шрифтов.
- Если в системе включено «Уменьшить движение», анимация не запускается.
